## 5. Hard constraints (from spec, non-negotiable)

## 12. How to use this template

1. Copy this file to your task directory: `cp templates/task-spec-packet.md <task_dir>/handoff-packet.md`
2. Fill every `<...>` placeholder with concrete values.
3. Run the lint: `python3 templates/lint_task_spec.py <task_dir>/handoff-packet.md`
4. Fix any `FAIL:` lines the lint prints.
5. Hand the file (and the spec it points to) to the receiving agent.
