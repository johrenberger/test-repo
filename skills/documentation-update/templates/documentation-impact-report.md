# Documentation impact report

Output of the
[`documentation-update`](../../../../skills/documentation-update/SKILL.md)
skill. Records which docs were updated, which were flagged as
needing owner action, which were out of scope, and any
contradictions found between doc areas. Save to
`/data/.openclaw/workspace/tasks/<TASK_ID>/reports/documentation-impact-report.md`.

## Field rules

- `Composite doc-risk` reflects the highest impact of any
  unresolved doc gap (e.g. `Critical` when public API docs
  contradict the actual contract).
- Every doc area is classified into exactly one of:
  `updated`, `flagged`, `out-of-scope`. The matrix above is
  the auditable evidence.
- `Contradictions found` is required when the doc set has
  internal disagreements. The skill does not resolve
  contradictions silently.
- `Validation evidence` is required for every updated doc
  that contains a runnable command or code example.
